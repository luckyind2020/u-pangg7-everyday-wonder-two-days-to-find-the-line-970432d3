One sentence that makes a small everyday moment strange and new: the shoes by the door, still pointing at the street, as if they slipped out before their owner did. The entry sentence lives in `entry.txt`; `main.py` reads it, checks it is a single sentence under the 200-character cap, and prints it unchanged.

## Run it

```sh
python3 main.py
```
